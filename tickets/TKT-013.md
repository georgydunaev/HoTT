## Task Description
Formalize Homotopy Fibers, Truncation Levels (Contractibility, Mere Propositions, Sets, n-Types), and Hedberg's Theorem in Homotopy Type Theory:
1. Formalize the Homotopy Fiber fib_f(y) := { x : A & f(x) = y } of a map f : A to B over y : B.
2. Prove that a map f : A to B is an equivalence if and only if all its homotopy fibers are contractible (forall y : B, isContr (fiber f y)).
3. Formalize truncation levels: contractible types (isContr A), mere propositions (isProp A), h-sets / 0-types (isSet A), and the inductive hierarchy of n-types (is_n_type n A).
4. Prove cumulativity of truncation: any contractible type is a proposition, any proposition is a set, and any n-type is an (n+1)-type.
5. Mechanize Hedberg's Theorem: Any type with decidable equality (forall x y : A, (x = y) + not (x = y)) is a 0-type / set (isSet A), via the method of collapsible path spaces and weakly constant endomaps.
