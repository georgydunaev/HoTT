## Task Description
Formalize Higher Inductive Types (HITs) with point constructors, path constructors, induction and elimination principles, computation rules (definitional on point constructors, propositional up to path on path constructors), and topological equivalence theorems:
1. Define the homotopical Interval type `I` with endpoints `zero`, `one` and 1-path `seg : paths zero one`. Prove `I` is contractible (`interval_is_contr : IsContr I`) and constructively derive Function Extensionality from Interval contractibility (`funext_from_interval`).
2. Define the Circle type `S1` with base point constructor `base : S1` and 1-path loop constructor `loop : paths base base`. Formulate `S1_ind`, `S1_rec`, and path constructor computation rules (`S1_ind_beta_loop`, `S1_rec_beta_loop`).
3. Define the Suspension type `Susp A` with constructors `north`, `south`, and meridian path constructor `merid : A to paths north south`. Formulate `Susp_ind`, `Susp_rec`, and computation rules (`Susp_ind_beta_merid`, `Susp_rec_beta_merid`). Prove that `Susp Bool` is equivalent to `S1` (`susp_bool_equiv_s1 : Equiv (Susp Bool) S1`).
4. Define the Torus type `T2` with base point `b : T2`, two 1-path loops `p, q : paths b b`, and a 2-path surface constructor `surf : paths (concat p q) (concat q p)`. Formulate `T2_ind`, `T2_rec`, computation rules, and the Torus surface commutativity lemma (`surf_commute`). Prove that `T2` is equivalent to `S1 * S1` (`torus_equiv_circle_prod : Equiv T2 (prod S1 S1)`).
5. Ensure 0 Admitted across all mechanizations using standard HoTT private inductive types and constructor/roundtrip axioms.
6. Register `theories/HigherInductiveTypes.v` in `_CoqProject`.
7. Implement Python reference models in `hott/hit.py` with Interval, Circle, Suspension, Torus ASTs, path constructors, recursors, fundamental group winding number evaluators, and topological cell structure checkers (CW complex dimensions, cell counts, Euler characteristic chi = V - E + F, and boundary operators). Re-export in `hott/__init__.py`.
8. Create comprehensive unit test suite in `tests/test_hit.py` and verify 100% pass across all tests and formal Coq theories in `run_tests.py` and `check.py`.
