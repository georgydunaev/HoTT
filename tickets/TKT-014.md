# [HOTT] Ticket TKT-014: Formalize Voevodsky Univalence Axiom, Constructive Function Extensionality, and Propositional Extensionality

## Task Description
Formalize Voevodsky's Univalence Axiom and its core structural consequences in Homotopy Type Theory:
1. Define the identity system and path induction principles (J eliminator, based path induction, path composition, inversion, groupoid laws, ap, transport).
2. Formulate the canonical map from paths to equivalences: idtoeqv : (A = B) -> (A <~> B).
3. State Voevodsky's Univalence Axiom asserting that idtoeqv is an equivalence (isequiv idtoeqv), providing the inverse map ua : (A <~> B) -> (A = B) and computation rules.
4. Formalize Univalence consequence 1: eqtoequiv_is_equiv (equivalence between identity paths and equivalences: (A = B) <~> (A <~> B)).
5. Formalize Univalence consequence 2: Function Extensionality derived constructively from Univalence:
   forall (f g : forall x : A, B x), (forall x, f x = g x) -> f = g.
   Show that postcomposition with an equivalence is an equivalence, that any equivalence has contractible fibers, that product of contractible types is contractible (weak function extensionality), and derive dependent and non-dependent function extensionality with 0 Admitted.
6. Formalize Univalence consequence 3: Equivalence of propositions is equality of propositions:
   isProp A -> isProp B -> (A <-> B) -> A = B.
7. Implement Python reference models for id_to_eqv, UnivalenceAxiom, eqtoequiv_is_equiv, weak_funext, funext_dep, funext_nondep, prop_equiv_to_id, and is_prop_equiv_is_id in hott/univalence.py, re-exporting in hott/__init__.py.
8. Provide unit test suite in tests/test_univalence.py and verify 100% pass rate in run_tests.py and check.py.

## Resolution
1. Formalized in Coq (theories/Univalence.v, registered in _CoqProject):
   - Defined paths, J, based_path_induction, concat, inverse, ap, transport, and verified homotopy groupoid laws (concat_1p, concat_p1, concat_p_pp, concat_Vp, concat_pV, inv_V, inv_pp).
   - Defined Homotopy, fiber, IsContr, IsEquiv, Equiv, isequiv_idmap, equiv_idmap, contr_retract.
   - Defined canonical map idtoeqv : (A = B) -> (A <~> B).
   - Stated univalence_axiom : forall (A B : Type), IsEquiv (idtoeqv A B) and inverse ua with computation rules ua_idtoeqv and idtoeqv_ua.
   - Proved Consequence 1: eqtoequiv_is_equiv : Equiv (paths A B) (Equiv A B).
   - Proved Consequence 2: Constructively derived Function Extensionality from Univalence:
     isequiv_postcompose, isequiv_to_contr_fibers, isequiv_pr1, weak_funext, funext_dep, and funext_nondep with 0 Admitted.
   - Proved Consequence 3: Propositional Extensionality:
     prop_equiv_to_id and is_prop_equiv_is_id : isProp A -> isProp B -> (A <-> B) -> paths A B with 0 Admitted.
   - Verified that Print Assumptions yields only univalence_axiom itself.

   - id_to_eqv, UnivalenceAxiom, eqtoequiv_is_equiv.
   - isequiv_postcompose, weak_funext, funext_dep, funext_nondep, strong_funext.
   - prop_equiv_to_id, is_prop_equiv_is_id.
3. Added unit tests in tests/test_univalence.py testing all three consequences.
4. Registered theories/Univalence.v in _CoqProject and run_tests.py.
5. Verified 100% test pass across all 32 unit tests and all 3 formal Coq theories in run_tests.py and check.py.
